# R0001: undeclared identifier

A name was used before it was declared, or is not visible in the current scope.

Declare the variable with `name := value` (or as a function parameter) before
referring to it, or check for a typo — the compiler suggests the closest known
name when one is near.

A `_` is a name too, unless it is a whole call argument: `f(a, _)` makes a capture,
`fn(v) { f(a, v) }`, but the `_` in `f(_ + 1)` reads a local named `_`. Without one it is
R0001, with a hint. Write the lambda out: `fn(v: int) { f(v + 1) }`.
