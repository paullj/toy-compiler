# T0069: or-pattern alternatives disagree

The alternatives of an or-pattern `A | B` share one arm, so each must bind the same
names with the same types: the arm reads them whichever alternative matched.

```
enum E { a(int), b(str) }

fn f(e: E) -> int {
    match e {
        E.a(x) | E.b(x) -> 1   // error: or-pattern alternatives must bind the same names and types
    }
}
```

Bind the same names with the same types in every alternative, or split the
alternatives into separate arms.
