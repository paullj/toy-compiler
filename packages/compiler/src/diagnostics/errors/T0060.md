# T0060: misplaced break or continue

A `break` or `continue` has no loop to act on, or acts on one in a way it cannot:

- `break` or `continue` outside any loop;
- `continue` naming a labeled block, which has no next iteration;
- `break` with a value out of a `while` or `for` loop, which yields no value (only a
  `loop` or a labeled block can).

```
fn main() -> int {
    break                      // error: break outside of a loop
    while true { break 1 }     // error: cannot break with a value out of a while/for loop
    @b { continue @b }         // error: cannot continue a labeled block (not a loop)
    return 0
}
```

A `break` or `continue` inside a lambda or local function cannot reach a loop
outside it either; that is T0051.

Fixes:

- Move the jump into the loop it is meant for, or return instead.
- Use `loop { .. }` to break out with a value.
