# W0001: unused variable

A local variable — a `:=`/typed binding, or a `for` loop variable — was declared
but never referenced. The binding does nothing, which usually means a typo, a
leftover from an edit, or a value you meant to use.

Prefix the name with an underscore to mark it deliberately unused: rename `i` to
`_i`, or use a bare `_` when you never need the value. This is a warning, so it
does not fail the build; `--deny-warnings` promotes it (and every warning) to an
error, and `--allow W0001` silences it.
