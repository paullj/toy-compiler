# T0041: binding type mismatch

A value's type is not assignable to the binding it is stored in: either the
initializer of an annotated `x: T = e` binding, or the right-hand side of an
assignment to an existing variable or field.

```
fn main() -> int {
    x: int = true   // error: cannot bind bool to 'x' of type int
    return x
}
```

A named field of a construction binds its value the same way: `Point { x: 1, y:
"two" }` is "field 'y': expected int, got str".

Fixes:

- Change the value so its type matches the binding.
- Change the annotation to the value's type, or drop it and write `x := e` to infer it.
- Convert explicitly, e.g. with `.into()` or `.try_into()`.
