# T0077: type too large

A struct or enum is larger than the largest value the compiler can build code for:
16,777,200 bytes, just under 16 MiB. A value of a type lives in a function's stack frame
whenever it is a local, a parameter or a temporary, and a frame cannot reach past that
size, so no value of this type could ever exist.

```
struct Row { a: int, b: int, c: int, d: int, e: int, f: int, g: int, h: int }   // 64 bytes
struct Page { r0: Row, r1: Row, /* ... */ r63: Row }                             // 4 KiB
struct Book { p0: Page, p1: Page, /* ... */ p4095: Page }                        // error: struct 'Book' is 16777216 bytes, over the 16777200-byte limit for a value
```

The error is reported once, at the type that first passes the limit. A type that holds
it is not reported again.

For a generic struct or enum, the error names the template ("an instance of struct
'Pair'") when one of its instances is too large for its type arguments. A prelude type has
no declaration to point at, so an instance of one is reported at the type it holds
("an instance of enum 'Option' holding 'Big'").

A type at the limit is still accepted, but a value of it fills a frame by itself, so a
function that holds one and anything else stops the build with "function frame too large
for codegen".

Hold large data in a `Vec` (`import std/vec`), whose elements live on the heap rather
than in the frame, and keep each element type small.
