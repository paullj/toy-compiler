# P0010: angle-bracket type arguments

Type arguments are written with square brackets, not the angle brackets `<>` used
by C++, Rust, or TypeScript. This error means a type was followed by `<...>` in a
type position — an annotation, a return type, a parameter, a field, or a nested
type argument.

    xs: Vec[int]                        // right
    fn first(xs: Vec[int]) -> int { }

Rewrite the angle brackets as square brackets: `Vec<int>` becomes `Vec[int]`,
`Map<str, int>` becomes `Map[str, int]`.

This check applies only in type positions. In an expression, `<` and `>` are the
comparison operators, so an expression-position turbofish (`f<T>(x)`) is parsed as
comparisons and is not diagnosed here.
