# T0067: pattern type mismatch

A `match` tests its scrutinee against patterns of the scrutinee's type. A scrutinee a
match cannot test (only an enum, an integer or a `bool` can be matched), or a pattern
of another type, is this error.

```
enum Color { red, green }
enum Size { small, big }

fn f(c: Color, n: int) -> int {
    match n { true -> 1, _ -> 0 }            // error: literal pattern type bool does not match scrutinee int
    match c { Size.small -> 1, _ -> 0 }      // error: pattern enum 'Size' does not match scrutinee 'Color'
    match n { Color.red -> 1, _ -> 0 }       // error: variant pattern on a non-enum scrutinee int
}
```

Fixes:

- Write patterns of the scrutinee's type.
- To branch on another type (a `str`, a struct), use `if` and `==`.
