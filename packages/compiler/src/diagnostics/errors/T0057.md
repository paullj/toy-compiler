# T0057: not indexable

`x[i]` reads an element of a `Vec`. Any other value has no index operator.

```
import std/map

fn main() -> int {
    n := 5
    a := n[0]            // error: cannot index a value of type 'int'
    m := Map[str, int].new()
    b := m["k"]          // error: Map has no index operator; use .get
    return a + b
}
```

A `Map` deliberately has none: a lookup can miss, so `m.get(k)` returns an
`Option` to say so. A store `m[k] = v` is this error too, with a hint to `m.set(k, v)`.

Only std's `Vec` is indexable: a program's own `struct Vec` is not.

Fixes:

- Index a `Vec`, or call the value's own lookup method (`m.get(k)`) or store method
  (`m.set(k, v)`).
