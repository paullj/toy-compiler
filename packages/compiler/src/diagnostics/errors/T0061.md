# T0061: no such variant

A variant construction, access or pattern names a variant the enum does not
declare. For a close misspelling the diagnostic suggests the intended variant.

```
enum Color { red, green }

fn main() -> int {
    c := Color.greem   // error: enum 'Color' has no variant 'greem'; did you mean 'green'?
    return 0
}
```

Use one of the declared variants, or add the variant to the enum.
