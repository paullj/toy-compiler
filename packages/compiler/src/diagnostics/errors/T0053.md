# T0053: a type parameter name is declared twice

Each type parameter of a function needs its own name. Every use of a name refers to
the first parameter that declares it, so a second one with the same name could never
be bound.

```
fn id[T, T](x: T) -> T { x }   // error: type parameter 'T' is declared twice
```

A method of a generic type has the impl's type parameters too, so its own may not
reuse one of their names:

```
struct Box[T] { v: T }
impl Box[T] {
    fn conv[T](self, x: T) -> T { x }   // error: type parameter 'T' is already the impl's
}
```

Rename the method's own parameter:

```
impl Box[T] {
    fn conv[U](self, x: U) -> U { x }
}
```
