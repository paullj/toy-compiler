# R0011: duplicate binding

One name is declared twice where only one can live: two parameters of one function
or lambda, two `:=` locals or local functions in one block, or two bindings in one
pattern. A secondary label points at the first declaration.

```
fn add(a: int, a: int) -> int { a }   // error: duplicate parameter 'a'

fn main() -> int {
    x := 1
    x := 2                            // error: redeclaration of 'x'
    return x
}
```

`_` is a name like any other here, so `fn(_, _) { .. }` declares `_` twice. To ignore
several parameters, give each its own `_`-prefixed name: `fn(_a, _b) { .. }`.

Fixes:

- Rename one of the two.
- To change a local's value, assign it (`x = 2`) instead of declaring it again.
