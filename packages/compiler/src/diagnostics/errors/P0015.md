# P0015: removed reference operator

The prefix operators `&x` and `*r` were removed. A shared mutable cell is now the
library type `Ref[T]` from `std/ref`, and you use it through ordinary methods:

    import std/ref

| Old syntax    | New code             |
|---------------|----------------------|
| `&x`          | `Ref.new(x)`         |
| `*r`          | `r.get()`            |
| `*r = v`      | `r.set(v)`           |
| `*r = *r + 1` | `r.set(r.get() + 1)` |

`Ref.new(x)` infers the cell type from `x`. Write `Ref[int8].new(x)` to choose it.
Every copy of a `Ref` names the same cell, so a `set` through one copy is seen
through all of them, and `==` compares cells.

You often need no cell at all. A plain local that a function changes can be a
`mut` parameter, and a local that a closure changes is shared with the closure
automatically:

    total := &0                 // before
    *total = *total + 1

    total := 0                  // after
    total = total + 1

The infix operators `a & b` (bitwise and) and `a * b` (multiply) are unchanged.
