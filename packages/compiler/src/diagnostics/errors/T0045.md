# T0045: condition is not bool

An `if` or `while` condition, or a match-arm guard, has a type other than
`bool`. Toy has no truthiness: integers, strings, and options are not
implicitly converted.

```
fn main() -> int {
    n := 3
    if n {   // error: if condition must be bool
        return 1
    }
    return 0
}
```

Fixes:

- Write the comparison you mean, e.g. `if n != 0`.
- Test an option with a `match` instead of using it as a condition.
