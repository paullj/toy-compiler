# T0038: unsafe required

Reading or writing through a raw pointer is only allowed inside an `unsafe { }`
block. A raw `store(ptr, value)` or `load(ptr)` dereferences an address the
compiler cannot prove valid, so it must be fenced explicitly.

```
p := gc_alloc(16)
store(p, 42)            // error: needs an unsafe block

unsafe { store(p, 42) } // ok
```

Fixes:

- Wrap the `store`/`load` in `unsafe { ... }`.
- Confine the unsafe region to the smallest span that actually needs it.
