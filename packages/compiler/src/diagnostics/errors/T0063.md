# T0063: wrong constructor form

A struct or a variant is constructed with the other form: a struct with named fields
is built with `S { field: value }`, a tuple struct or a tuple variant with
`S(value, ..)`, and a variant with named fields with `E.v { field: value }`.

```
struct Point { x: int, y: int }
enum Shape { circle(int), rect { w: int, h: int } }

fn main() -> int {
    p := Point(1, 2)        // error: use named construction 'Point { ... }', not 'Point(...)'
    s := Shape.rect(1, 2)   // error: variant 'Shape.rect' is constructed with the wrong form
    return 0
}
```

Write the form the declaration has.
