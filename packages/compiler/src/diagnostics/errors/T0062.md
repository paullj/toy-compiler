# T0062: not an enum

A variant is named on a type that is not an enum, or a leading-dot variant `.v` has
no enum to come from.

```
struct P { x: int }
enum E { a, b }

fn f(e: E) -> int {
    match e {
        P.x -> 1       // error: 'P' is not an enum type
        _ -> 0
    }
}

fn main() -> int {
    b := .some         // error: cannot infer the enum type for '.some' here
    n: int = .red      // error: '.red' expects an enum type, but int was expected here
    return f(E.a)
}
```

A `.v` takes its enum from the type expected where it is written: an annotated
binding, a parameter, a return position or a match on an enum.

Fixes:

- Name the enum: `Color.red`.
- Give the binding an enum type, so `.v` knows which enum it is.
