# T0021: no conformance

An `impl <T> has <P>` block does not satisfy the protocol `P`, either because `P` is
not a declared protocol, or because the impl omits a method that `P` requires. An
`impl .. has P` must provide every method the protocol declares (matched by name).

```
protocol Named { fn name(self) -> int }
struct P { x: int }

impl P has Named {          // error: impl of protocol 'Named' for 'P' is missing method 'name'
    fn other(self) -> int { self.x }
}

impl P has Ghost {          // error: 'Ghost' is not a declared protocol
    fn name(self) -> int { self.x }
}
```

Add the missing method (with `self` as its first parameter and a matching name), or
fix the protocol name in the `has` clause.
