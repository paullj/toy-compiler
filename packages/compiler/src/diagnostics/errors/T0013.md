# T0013: generics not yet supported

Generic syntax parses — `fn f[T](..)`, `struct Box[T]`, `enum E[T]`, a type
application `Box[int]`, and explicit call type-args `f[int](..)` all build a
well-formed AST — but the type checker does not yet give it any meaning, so every
generic declaration and type-application is rejected here and no code is emitted.

Remove the type parameters (and any `[..]` type-application) to compile the
program with concrete types for now.
