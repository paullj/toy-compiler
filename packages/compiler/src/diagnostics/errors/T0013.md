# T0013: generics not yet supported

Generic syntax parses — `fn f[T](..)`, `struct Box[T]`, `enum E[T]`, a type
application `Box[int]`, and explicit call type-args `f[int](..)` all build a
well-formed AST — but the type checker does not yet give it any meaning, so every
generic declaration and type-application is rejected here and no code is emitted.

Remove the type parameters (and any `[..]` type-application) to compile the
program with concrete types for now.

## Methods

A method of a generic type may declare type parameters of its own
(`impl Box[T] { fn map[U](self, f: fn(T) -> U) -> Box[U] }`), inferred at each call.
A method of a non-generic type cannot yet: its calls are rejected here.

```
struct P { v: int }
impl P {
    fn conv[U](self, f: fn(int) -> U) -> U { f(self.v) }
}

fn main() -> int {
    p := P { v: 4 }
    return p.conv(fn(x: int) { x * 3 })  // error: 'conv' declares its own type parameters
}
```

Make the method a generic fn (`fn conv[U](p: P, f: fn(int) -> U) -> U`), or drop
its type parameters.
