# T0046: no such field

A field access, a struct or variant construction, or a pattern names a field
that the struct or enum variant does not declare. For a close misspelling the
diagnostic suggests the intended field. Tuple structs only have the positional
fields `.0`, `.1`, and so on.

```
struct Point { x: int, y: int }

fn main() -> int {
    p := Point { x: 6, y: 7 }
    return p.z   // error: no field 'z' in struct 'Point'
}
```

Fixes:

- Use one of the declared field names (check the "did you mean" suggestion).
- Add the field to the struct or variant declaration.
- For a tuple struct, index positionally with `.0`, `.1`, ...
