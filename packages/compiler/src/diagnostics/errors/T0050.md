# T0050: cannot infer a lambda parameter's type

A lambda parameter has no type annotation, and nothing around the lambda says
what its type is. A lambda takes its parameter types from the function type
expected where it is written: an annotated binding, a parameter of a known
function, a return position, a struct field or a `Vec` element. Without one,
every parameter needs a `: T`.

```
fn apply[T](f: fn(T) -> T, x: T) -> T { f(x) }

fn main() -> int {
    g := fn(x) { x + 1 }            // error: nothing expects a function type here
    return apply(fn(x) { x }, 1)   // error: a generic call does not provide one yet
}
```

Fixes:

- Annotate the parameter: `fn(x: int) { x + 1 }`.
- Or give the binding a function type: `g: fn(int) -> int = fn(x) { x + 1 }`.
