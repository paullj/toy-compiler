# T0051: break or continue across a lambda

A `break` or `continue` inside a lambda or a local function targets a loop (or
a labeled block) outside it. The lambda is a separate function: it may run after
the loop has finished, or not at all, so it cannot jump into its caller's loop.
This holds for bare and labeled jumps alike. Loops inside the lambda work as
usual.

```
fn main() -> int {
    @outer for _i in 0..3 {
        f := fn() {
            break @outer   // error: cannot break a loop outside this lambda
        }
        f()
    }
    return 0
}
```

Fixes:

- Return a value from the lambda and branch on it in the loop:
  `if f() { break }`.
- Move the loop into the lambda.
