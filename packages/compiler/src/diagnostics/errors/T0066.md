# T0066: sugar needs an import

A list literal `[a, b]` and an index `xs[i]` are shorthand for `std/vec`'s `Vec`, so
the module that writes them must import `std/vec`, even when the `Vec` itself came
from elsewhere (a `Map`'s `keys()`).

```
import std/map

fn main() -> int {
    m := Map[int, int].new()
    ks := m.keys()
    return ks[0]       // error: indexing a 'Vec' needs 'Vec' in scope; add 'import std/vec'
}
```

Add `import std/vec`. A method call (`ks.get(0)`) needs no import: it names the
method on the value, not `Vec`.
