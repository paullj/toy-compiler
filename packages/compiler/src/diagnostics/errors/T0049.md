# T0049: function is not a value

A function or a method is named as a value (`f := g`, `apply(g)`, `h := acc.m`, a
struct field or a `Vec` element) but it has no single piece of code a function
value could point at:

- a builtin such as `panic` is expanded by the compiler at each call;
- an `extern` function is a symbol of another library, reached only by a call;
- a generic function or method exists only as its instances, one per set of type
  arguments;
- a built-in method (a scalar or `str` method such as `s.len`, `into`/`try_into`,
  the derivable `hash` and `to_string`, a method of `Option` or `Result`) is
  expanded by the compiler at each call;
- a protocol method of a type parameter (`x.area` where `x: T` and `T has Shape`)
  names no method until the function is instantiated;
- a function with a `mut` parameter, or a method with a `mut` parameter after
  `self`: a call through a function value passes every argument by value, so it
  could not pass the caller's place. (A `mut self` method alone can be bound:
  `f := acc.bump`.)

An associated function named through its type is a value (`f := K.make`,
`f := Box[int].new`) unless one of these applies: it has type parameters of its own
or a `mut` parameter.

```
fn id[T](x: T) -> T { x }

fn main() -> int {
    f := panic   // error: 'panic' is a builtin and cannot be used as a value
    g := id      // error: 'id' is a generic function and cannot be used as a value
    s := "hi"
    n := s.len   // error: 'len' is a built-in method and cannot be used as a value; wrap the call in a lambda
    b := bump    // error: 'bump' is a function with 'mut' parameters and cannot be used as a value
    return 0
}

fn bump(mut n: int) { n = n + 1 }
```

Fixes:

- Wrap the call in a lambda or a named function of the wanted type, and pass that:
  `n := fn() -> int { s.len() }`, or `fn id_int(x: int) -> int { id(x) }`, then
  `g := id_int`.
- Call the function directly instead of storing it.

Type arguments do not make a generic function a value either: `f := id[int]` is this
error. Wrap the call in a lambda, as in `fn(x: int) { id[int](x) }`.
