# T0049: function is not a value

A function is named as a value (`f := g`, `apply(g)`, a struct field or a
`Vec` element) but it has no single piece of code a function value could point
at:

- a builtin such as `panic` is expanded by the compiler at each call;
- an `extern` function is a symbol of another library, reached only by a call;
- a generic function exists only as its instances, one per set of type
  arguments.

```
fn id[T](x: T) -> T { x }

fn main() -> int {
    f := panic   // error: 'panic' is a builtin and cannot be used as a value
    g := id      // error: 'id' is a generic function and cannot be used as a value
    return 0
}
```

Fixes:

- Wrap the call in a named function of the wanted type, and pass that:
  `fn id_int(x: int) -> int { id(x) }`, then `g := id_int`.
- Call the function directly instead of storing it.
