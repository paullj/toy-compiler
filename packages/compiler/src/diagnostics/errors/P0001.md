# P0001: expected token

The parser reached a point where a specific punctuation mark or keyword was
required (for example a `)`, `{`, `:`, or `=`) but found something else.

Check for a missing or misplaced delimiter near the reported location.

A block that runs into the end of the file is missing its `}`. Inside a block,
`fn name(..)` declares a local function, so when a function's closing `}` is
missing, every top-level function after it parses as nested in it and the error
only appears at the end of the file. The error then points at the `fn` it
suspects, preferring one written in column 1:

```
fn main() -> int {
    if true {
        return 1
    return 0
}                  // closes the `if`, not `main`

fn other() -> int { 2 }   // parsed as a nested function
```

Add the missing `}` before that `fn`.

A method takes `self` and a local function never does, so inside an `impl`
the next method ends a method body that lost its `}`, and the error is reported
at that method:

```
impl C {
    fn a(self) -> int {
        if true { 1 } else { 2 }
                   // a's `}` is missing
    fn b(self) -> int { 2 }   // error: expected '}' to close block
}
```
