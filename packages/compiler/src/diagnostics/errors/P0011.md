# P0011: C-style for loop

toy has no C-style `for (init; condition; step)` loop. This error means a `for` was
followed by a parenthesised header. A `for` iterates a range or an iterable:

    for i in 0..n { }      // a half-open range [0, n)
    for x in xs { }        // any iterable
    for k, v in m { }      // key/value pairs

For a manual counter, use a `while` loop.
