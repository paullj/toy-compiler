# R0010: extern not in core (retired)

This code is retired: any module may declare an `extern fn` or an `extern "lib" { .. }`
block, and every call to one sits inside `unsafe { }` (**T0079**). Historically only a
bundled `core/` module could declare an extern, and the extern was then left
unregistered, so each use of its name was also an R0001.
