# T0001: unknown type

A type annotation, or the type named in a construction (`Name { .. }`), is a type the
compiler cannot resolve. Check the spelling, and that any struct/enum type is declared
or imported into scope.

```
struct Point { x: int, y: int }

fn main() -> int {
    p := Pointt { x: 1, y: 2 }   // error: unknown struct type 'Pointt'
    return p.x
}
```

`never` is also reported here when it names anything but a function's return type. No
value of `never` can exist, so a param, field, binding or type argument of it is an
error unless a user type named `never` is in scope.
