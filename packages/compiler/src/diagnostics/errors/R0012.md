# R0012: import cycle

Following the imports from this module leads back to a module that is still being
imported, so no module of the cycle can be checked before the others. The error sits
on the import that closes the cycle and lists the modules in it.

```
// a.toy
import b        // error: import cycle detected: a -> b -> a

// b.toy
import a
```

A module that imports itself is a cycle too, and so are re-exports that loop: a
`pub import` is an import, so `a` re-exporting a name from `b` while `b` re-exports one
from `a` is this error.

Fixes:

- Move what both modules need into a third module that both import.
- Or merge the modules.
