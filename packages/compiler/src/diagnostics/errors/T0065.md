# T0065: list literal type mismatch

A list literal `[a, b, ..]` builds a `Vec` whose element type is its first element's
(or the annotation's). An element of another type, an annotation of another element
type, or a place that wants something other than a `Vec` is this error.

```
import std/vec

fn main() -> int {
    a := [1, "two"]          // error: list element 1: expected 'int', got 'str'
    b: Vec[str] = [1, 2]     // error: list element type 'int' does not match the annotation's 'str'
    n: int = [1, 2]          // error: a list literal of type 'Vec' cannot produce 'int'
    return 0
}
```

An empty `[]` with no annotation has no element type at all: that is T0016.

Fixes:

- Give every element the same type.
- Make the annotation agree with the elements.
