# T0059: value if without else

An `if` whose result is used must have an `else`: with none, the condition being
false leaves no value.

```
fn main() -> int {
    x := if true { 1 }   // error: value-if requires else
    return x
}
```

Add an `else` arm with a value of the same type, or use the `if` as a statement.
