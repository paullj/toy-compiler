# W0003: unused function

A non-`pub` top-level function is never called anywhere in the module graph. It is
dead code: nothing references it, so it contributes nothing and usually means a typo,
a leftover from an edit, or an intended call that was never wired up.

Remove the function, or make it `pub` if it is part of the module's intended API and
callers live elsewhere. To keep a deliberately-unused stub without a warning, prefix
its name with an underscore: rename `helper` to `_helper`.

A function that only ever calls itself still counts as unused — a recursive call is a
call site, so it does not warn. Methods, `pub` functions, `extern` functions, and the
entry `main` never warn.

This is a warning, so it does not fail the build; `--deny-warnings` promotes it (and
every warning) to an error, and `--allow W0003` silences it.
