# T0047: missing field

A struct or enum-variant construction leaves out a field the type declares.
Every field must be given a value; there are no implicit defaults.

```
struct Point { x: int, y: int }

fn main() -> int {
    p := Point { x: 6 }   // error: missing field 'y' in 'Point'
    return p.x
}
```

Fixes:

- Supply a value for every declared field.
- Remove the field from the declaration if it is not needed.
