# P0003: expected declaration

At the top level the parser expected a declaration — a function, struct, enum,
or import (and, after `pub`, one of function, struct, or enum) — but found
something else.

Begin the item with the appropriate keyword (`fn`, `struct`, `enum`, or
`import`).

A declaration can also be malformed in a way its keyword does not allow: an
`extern` function or a local function (a `fn` declared inside a block) cannot
take type parameters. Move a generic helper to the top level:

```
fn main() -> int {
    fn id[T](x: T) -> T { x }   // error: local functions cannot be generic
    return id(1)
}
```
