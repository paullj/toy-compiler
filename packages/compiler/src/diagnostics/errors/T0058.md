# T0058: branches of different types

A value `if` (one whose result is used) has a `then` and an `else` arm that yield
different types, so the `if` has no single type.

```
fn pick(c: bool) -> int {
    if c { 1 } else { "one" }   // error: branches yield different types (int vs str)
}
```

Make both arms yield the same type, converting one if needed.
