# T0070: assignment to a field of an index element (retired)

This code is retired: a field of a `Vec` element can be stored. `xs[i].f = v` copies
the element in, stores the field and writes the element back, and `xs[i].f op= v`
reads the field, applies `op` and stores the result the same way, evaluating `xs` and
`i` once. Historically this code rejected every store to a field of an index element,
since the element was only read as a copy, and later only the compound one.
