# T0070: assignment to a field of an index element

`xs[i]` reads a copy of the element, so `xs[i].f = v` would write the copy and lose
the write.

```
import std/vec

struct P { x: int }
struct H { ps: Vec[P] }

fn main() -> int {
    h := H { ps: [P { x: 1 }] }
    h.ps[0].x = 5   // error: cannot assign to a field of an index element `xs[i].field`; the element is a temporary copy, so the write would be lost
    return h.ps[0].x
}
```

The same holds for a local `Vec`: `ps[0].x = 5` is this error too. A `Vec` element is
not a place, but a whole element can be stored: copy it out, change the copy, and
store it back.

```
    p := h.ps[0]
    p.x = 5
    h.ps[0] = p
```
