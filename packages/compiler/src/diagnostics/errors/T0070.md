# T0070: compound assignment to a field of an index element

`xs[i].f = v` stores a field of the element in the `Vec`: it copies the element in,
stores the field and writes the element back. A compound operator on an element field
(`xs[i].f += v`) is not supported yet.

```
import std/vec

struct P { x: int }

fn main() -> int {
    ps: Vec[P] = [P { x: 1 }]
    ps[0].x += 5   // error: cannot assign to a field of an index element `xs[i].field` with a compound operator; write `xs[i].field = xs[i].field op v`
    return ps[0].x
}
```

Write the long form, `ps[0].x = ps[0].x + 5`. Historically this code rejected every
store to a field of an index element, since the element was only read as a copy.
