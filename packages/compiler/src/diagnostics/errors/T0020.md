# T0020: overlapping impl

Two `impl <T> has <P>` blocks conform the SAME type to the SAME protocol. Conformance
is coherent WHOLE-PROGRAM: there may be exactly one impl per (protocol, type) pair
across every module — including a "retroactive" impl in a sibling module that conforms
an imported type to an imported protocol. There are no orphan rules; the constraint is
simply uniqueness.

```
// lib.toy
pub protocol Show { fn show(self) -> int }
pub struct W { n: int }
impl W has Show { fn show(self) -> int { self.n } }

// dup.toy
import lib
impl lib.W has lib.Show {           // error: overlapping impl of protocol 'Show' for type 'W'
    fn show(self) -> int { 0 }
}
```

Remove the duplicate impl. If two modules each need `W` to be `Show`, define that one
conformance in a single module both can import.
