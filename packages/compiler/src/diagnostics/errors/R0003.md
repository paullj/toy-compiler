# R0003: unknown imported module

An `import` refers to a module path that does not resolve to a file in the build
graph: no `<path>.toy` exists under the module root (the entry module's directory),
or the path leads outside that root.

```
import util/strs   // error: imported module 'util/strs' not found (looked for 'util/strs.toy')
```

Check the path spelling and that the file exists. The match is case-sensitive even on
a file system that is not: `import Util` does not open `util.toy`.
