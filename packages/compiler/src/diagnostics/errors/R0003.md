# R0003: unknown imported module

An `import` refers to a module path that does not resolve to a file in the build
graph: no `<path>.toy` or folder module `<path>/mod.toy` exists under the module root
(`--root`, default the entry module's directory) or any extra root (`-I`), or the path
leads outside the root. The message lists every file it looked for.

```
import util/strs   // error: imported module 'util/strs' not found (looked for 'util/strs.toy', 'util/strs/mod.toy')
```

Check the path spelling and that the file exists. The match is case-sensitive even on
a file system that is not: `import Util` does not open `util.toy`.

A path whose last segment is `mod` is also this error: `util/mod.toy` is the folder
module `util`, so write `import util`, not `import util/mod`.
