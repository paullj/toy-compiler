# T0075: assignment to a field of a temporary

A field is assigned through a value that has no home of its own, such as a call
result. The value is a copy, so the write would change the copy and be lost.

```
struct P { x: int }
impl P { fn moved(self, d: int) -> P { P { x: self.x + d } } }

fn main() -> int {
    p := P { x: 1 }
    p.moved(1).x = 5   // error: cannot assign to a field of a temporary value, such as a call result; it is a copy, so the write would be lost
    return p.x
}
```

Only a local, or a field or tuple field of one, can be assigned. Bind the value to a
local first, change the local, and use it: `q := p.moved(1)`, then `q.x = 5`. A field
of an index element (`xs[i].f = v`) is T0070, for the same reason.
