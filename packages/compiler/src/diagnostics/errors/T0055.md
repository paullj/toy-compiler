# T0055: not callable

A call `f(..)` whose `f` is not a function: a value of another type, a module, or
an enum.

```
import std/io

enum Color { red, green }

fn main() -> int {
    x := 1
    a := x(2)       // error: called value is not a function
    b := io(5)      // error: module 'io' is not a function; call one of its functions, as in 'io.f(..)'
    c := Color(1)   // error: enum 'Color' is not a function; construct one of its variants, as in 'Color.v(..)'
    5 |> io         // the same error: a pipe calls its target
    return 0
}
```

A struct name used as a call is T0063 instead (construct it with `S { .. }`).

Fixes:

- Call a function: a named fn, a method, or a value of function type.
- For a module, call one of its functions; for an enum, construct a variant.
