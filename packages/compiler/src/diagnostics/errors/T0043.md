# T0043: missing return

A function declares a non-unit return type, but some path through its body
reaches the end without returning a value.

```
fn sign(n: int) -> int {   // error: function 'sign' must return int but may fall off the end
    if n > 0 {
        return 1
    }
}
```

A body that does end in a value, but one of the wrong type (`fn f() -> bool { 1 }`),
is T0042 at that value instead.

Fixes:

- Add a `return` (or a trailing expression) on every path, e.g. an `else` branch.
- End the body with a value of the return type after the conditional.
- Drop the `-> T` if the function is not meant to produce a value.
