# R0007: invalid assignment target

The left-hand side of an assignment is not an assignable place: it names an
undeclared variable, a function (a top-level one, or a local `fn` declared in a
block), or a module, or it is a value with no name, such as a call result
(`p.get() = v`). Only variables, and fields of them, can be assigned to. To swap in a different
function, bind a variable of the function type instead: `f := helper`, then
`f = other`.

If the name is new, declare it first with `:=`, then reassign with `=`:

    count := 0             // declare
    count = count + 1      // reassign
