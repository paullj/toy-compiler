# T0044: operand type mismatch

An operator is applied to operands whose types it does not accept. Binary
operators need both sides to have the same type (arithmetic on `int` or
`float`, `&&`/`||` on `bool`, bitwise and `%` on `int`); unary `-` and `~` need
an `int`, and `!` needs a `bool`.

```
fn main() -> int {
    return 1 + "two"   // error: operands of '+' must have the same type
}
```

An index and the bounds of a `for` range are operator operands too: `xs["0"]` is "an
index must be 'int', got 'str'", and `for i in 0.."3"` is "for range bounds must be
int".

A compound assignment `place op= v` checks as `place = place op v`, so its operands
follow the same rules and the error points at the operator: `x += true` on an `int`
is "operands of '+=' must have the same type". The float forms `+.=`, `-.=`, `*.=`
and `/.=` take floats on both sides, like `+.`.

Fixes:

- Make both operands the same type, converting one with `.into()` if needed.
- Use the operator that matches the operand type (e.g. `!` for bool, `-` for numbers).
