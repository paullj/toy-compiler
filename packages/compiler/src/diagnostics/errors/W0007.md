# W0007: constant condition

An `if` condition is a bare `true` or `false` literal. The test never varies: the same
branch runs every time, and the other branch is dead. A constant condition is almost
always leftover debug code — a branch temporarily forced on or off — or a mistake, and
in either case the `if` is not doing what an `if` is for.

This warns only on a DIRECT boolean literal in the condition: `if true` and `if false`,
in both statement position (`if true { .. } else { .. }`) and value position
(`x := if true { .. } else { .. }`). It is not general constant folding: an expression
that merely evaluates to a constant — `1 == 1`, `!true`, or a variable bound to a
constant — is not flagged. `while true` is a separate construct (a deliberate infinite
loop is idiomatic) and is never flagged.

Fix it by restoring the real condition, or by deleting the dead branch and keeping only
the arm that runs. If the constant is intentional, `--allow W0007` silences the warning.
This is a warning, so it does not fail the build; `--deny-warnings` promotes it (and
every warning) to an error.
