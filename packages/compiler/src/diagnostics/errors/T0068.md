# T0068: pattern arity mismatch

A variant pattern binds a different number of values than the variant holds.

```
enum Shape { circle(int), rect(int, int), empty }

fn area(s: Shape) -> int {
    match s {
        Shape.circle(r) -> r * r * 3
        Shape.rect(w) -> w          // error: variant 'Shape.rect' binds 2 value(s), got 1
        Shape.empty(e) -> e         // error: unit variant 'Shape.empty' binds no payload
    }
}
```

Bind one name (or `_`) per value the variant holds, and none for a unit variant.
