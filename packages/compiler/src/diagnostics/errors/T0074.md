# T0074: assignment to an index element (retired)

This code is retired: an element of a `Vec` can be stored. `xs[i] = v` means
`xs.set(i, v)`, and `xs[i] op= v` reads the element, applies `op` and stores the
result, evaluating `xs` and `i` once. Historically this code rejected both forms, and
later only the compound one.
