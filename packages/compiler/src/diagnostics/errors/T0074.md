# T0074: compound assignment to an index element

`xs[i] = v` stores a whole element, but a compound operator on an element
(`xs[i] += v`) is not supported yet.

```
import std/vec

fn main() -> int {
    xs: Vec[int] = [1, 2, 3]
    xs[1] += 7   // error: cannot assign to an index element `xs[i]` with a compound operator; write `xs[i] = xs[i] op v`
    return xs[1]
}
```

Write the long form, `xs[1] = xs[1] + 7`. A field of an index element (`xs[i].f = v`)
is T0070.
