# T0074: assignment to an index element

`xs[i]` reads a copy of the element; it is not a place a value can be stored to, and
`Vec` has no index assignment.

```
import std/vec

fn main() -> int {
    xs: Vec[int] = [1, 2, 3]
    xs[1] = 7   // error: cannot assign to an index element `xs[i]`; a 'Vec' element is not a place and 'Vec' has no index assignment
    return xs[1]
}
```

Only a local, or a field or tuple field of one, can be assigned. A field of an index
element (`xs[i].f = v`) is T0070 for the same reason. Keep a value you need to update in
a local or a struct field, or build a new `Vec` with the changed elements (`xs =
xs.map(..)`, or a loop that pushes onto a new one).
