# T0072: mut self method bound on a field

A bound `mut self` method value (`f := c.bump`) writes its receiver on every call, so
the receiver must live in a box, and only a local variable can be moved into one: a
field is part of the value around it.

```
struct Counter { n: int }
impl Counter { fn bump(mut self) { self.n = self.n + 1 } }
struct Holder { c: Counter }

fn main() -> int {
    h := Holder { c: Counter { n: 0 } }
    inc := h.c.bump   // error: binding the 'mut self' method 'bump' needs a local receiver, not a field; bind it on a local variable
    inc()
    return h.c.n
}
```

Bind the method on a local and store it back: `c := h.c`, `inc := c.bump`, then
after the calls `h.c = c`. Or call it directly: `h.c.bump()`.
