# T0056: not a value

A type, a protocol or a module is named where a value is wanted. A type names a kind
of value, a protocol a set of methods, and a module a set of declarations; none is
itself a value that can be stored, passed or piped. Every type-level name counts: a
struct, an enum, a builtin type, an alias, a type parameter, or another module's type.

```
import std/io

struct Point { x: int, y: int }
enum Color { red, green }

fn main() -> int {
    p := Point          // error: type 'Point' is not a value
    c := Color          // error: type 'Color' is not a value; name one of its variants, as in 'Color.red'
    n := int            // error: type 'int' is not a value
    m := io             // error: module 'io' is not a value
    io |> .println("a") // error: module 'io' is not a value, so it cannot be piped; use 'io.println' directly
    return 0
}
```

Fixes:

- Construct a value of the type (`Point { x: 1, y: 2 }`), name a variant of an enum
  (`Color.red`), or call one of the type's associated functions (`Point.origin()`).
- Name a member of the module (`io.println`) instead of the module.
