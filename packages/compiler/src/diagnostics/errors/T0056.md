# T0056: not a value

A type or a module is named where a value is wanted. A type names a kind of value,
and a module a set of declarations; neither is itself a value that can be stored,
passed or piped.

```
import std/io

struct Point { x: int, y: int }

fn main() -> int {
    p := Point          // error: type 'Point' is not a value
    m := io             // error: module 'io' is not a value
    io |> .println("a") // error: module 'io' is not a value, so it cannot be piped; use 'io.println' directly
    return 0
}
```

Fixes:

- Construct a value of the type (`Point { x: 1, y: 2 }`), or call one of its
  associated functions (`Point.origin()`).
- Name a member of the module (`io.println`) instead of the module.
