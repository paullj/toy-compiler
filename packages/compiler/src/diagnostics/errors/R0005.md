# R0005: item is not exported

A referenced struct, enum, protocol, type alias, or function exists in the target
module but is not `pub`, so no other module can name it: neither qualified
(`module.item`) nor through a selective import (`import a/b.{item}`). Mark the
declaration `pub` in its defining module to export it.

A name a module imports is its own too: only a `pub import` re-exports it. So
`util.helper` is this error when `util` has `import inner.{helper}`, and fine when it
has `pub import inner.{helper}`. The same holds for a namespace (`util.inner.f()` needs
`pub import inner` in `util`).
