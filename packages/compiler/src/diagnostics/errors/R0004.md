# R0004: import namespace collision

A name an import binds collides with a top-level declaration or with a name an earlier
import binds. A whole-module import binds its namespace (the last path segment, or its
`as` alias); a selective import binds each name it lists (or each item's `as` alias).
Each name binds once per module.

```
import std/io.{println, print}
import std/fs.{exists as print}   // error: imported name 'print' collides with
                                  // an earlier import
import std/fs.{open}              // error: imported name 'open' collides with a
                                  // top-level declaration named 'open'
fn open() {}
```

Fix it by renaming one side: `import a/b as name` for a whole module, or
`import a/b.{item as name}` for a selected item.
