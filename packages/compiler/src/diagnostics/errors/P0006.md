## `mut` on a parameter

`mut` before a parameter name makes the call pass the caller's place by address.
Only a function called by name or as a method can take one, so `mut` is allowed on
the parameters of a top-level function and of a method in an inherent `impl`
(an associated function's included), and on any `self` receiver. It is an error on:

- a lambda's or a local function's parameters: they are called as a value, which
  passes every argument by value;
- an `extern` function's parameters: the C ABI passes values;
- a protocol method's parameters after `self`, in the protocol or in a conforming
  `impl`: protocol code passes arguments by value;
- any parameter after the first 64.

```
protocol Shape {
    fn scale(self, mut by: int)   // error: 'mut' may only qualify the 'self' receiver of a protocol method
}

fn main() -> int {
    f := fn(mut a: int) -> int { a }   // error: a lambda's parameters cannot be 'mut'
    return f(1)
}
```

Drop the `mut` and return the new value instead, or move the code into a top-level
function.
