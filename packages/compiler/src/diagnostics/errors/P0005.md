# P0005: nesting too deep

A block or expression was nested more deeply than the parser's fixed recursion
limit allows. This limit is a safety backstop that keeps deeply nested (or
runaway) input from exhausting the stack.

A long flat chain also counts, because each step nests the part before it:
`a + b + c` is `(a + b) + c`, a pipe `x |> f |> g` is `g(f(x))`, and `x.f.g()` nests
each postfix. More than 256 levels in one expression is this error.

Flatten the code so it nests less deeply near the reported location, for example by
binding part of a long chain to a local first.
