# T0052: a lambda captures a variable

A lambda names a local variable or parameter of the function it is written in.
Closures that capture variables are not supported yet: a lambda may use only
its own parameters and locals, named functions, and the other names in scope
at the top level.

```
fn main() -> int {
    base := 10
    f := fn(x: int) -> int { x + base }   // error: this lambda captures 'base'
    return f(1)
}
```

Fixes:

- Pass the value in as a parameter: `f := fn(x: int, b: int) -> int { x + b }`, then `f(1, base)`.
- Or move the lambda's work into a named function that takes it as an argument.
