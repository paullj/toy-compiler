# T0052: a closure cannot capture this variable yet

A lambda may name the locals and parameters of the function it is written in: it
captures them. A capture is copied into the closure when the closure is made, so
two kinds of capture are not supported yet:

- A captured local that is also **assigned** anywhere in the function, inside or
  outside the lambda: `x = ..`, a field store `x.f = ..`, or a call of a
  `mut self` method on `x`. The copy would not see the assignment.
- Any capture of a **`mut self` receiver**. Inside a `mut self` method, `self`
  refers to the caller's variable, not to a value the closure can copy.

```
fn main() -> int {
    total := 0
    add := fn(x: int) { total = total + x }   // error: 'total' is captured by a closure and assigned
    add(1)
    return total
}
```

```
impl Counter {
    fn report(mut self) -> int {
        f := fn() -> int { self.n }   // error: a closure cannot capture the 'mut self' receiver 'self'
        f()
    }
}
```

Reading a captured local is fine, and so is calling a plain `self` method on it
or pushing onto a captured `Vec` (the handle is copied; the `Vec` is shared).

Fixes:

- Give the lambda the value it needs and return the new one: `add := fn(t: int, x: int) -> int { t + x }`, then `total = add(total, 1)`.
- For a `mut self` receiver, copy what the lambda reads into a local first: `n := self.n`, then `f := fn() -> int { n }`.
