# T0031: value does not conform to `Display`

`x.to_string()` renders any value whose type conforms to the prelude `Display` protocol.
`Display.display(self) -> str` builds the value's rendering as a `str`; `to_string(x)`
returns it (and `io.print(x)` writes it), so the same error gates both. The builtin scalars
(`int`/`bool`/`str`/`unit`) always conform, and a struct or enum with NO explicit `impl`
derives `Display` structurally when EVERY field's type conforms (recursively). So
`"hi".to_string()`, `42.to_string()`, and `P{ x: 4, y: 2 }.to_string()` all work with no
`impl` in sight.

The derive fires only when it can. If a field's type does NOT conform to `Display`, the
struct cannot derive it, and the `to_string` call reports the FIRST offending field by name:

```
enum Color { R(int), G, B }
impl Color has Eq { fn eq(self, o: Color) -> bool { true } }
struct Bad { c: Color }   // Color has no `Display` conformance

fn main() {
    s := Bad{ c: Color.G }.to_string()
    // error: cannot 'to_string' a 'Bad': field 'c' of type 'Color' does not conform to 'Display'
}
```

A generic parameter needs a `Display` bound, else the compiler cannot know the concrete type
conforms. The bound is checked at INSTANTIATION, so the error surfaces at the use site
(where a concrete non-conforming type is supplied) as a **T0023** conformance failure — an
uninstantiated generic body reports nothing:

```
fn show[T has Display](x: T) -> str { x.to_string() }
fn main() {
    s := show(Bad{ c: Color.G })
    // error[T0023]: type 'Bad' does not conform to protocol 'Display'
}
```

Two fixes:

- Make the offending field's type conform (give it its own `impl`, or let it derive
  structurally by making ITS fields conform).
- Or give the type an explicit `impl Bad has Display { fn display(self) -> str { .. } }`,
  which overrides the derive entirely (an explicit impl always wins). The method returns
  the rendering as a `str`.

The derive is lazy: an unused type synthesizes no code. It only runs at a `to_string` use
site, which is where this error surfaces.
