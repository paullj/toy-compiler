# T0036: malformed char literal

A `char` literal `'…'` must hold exactly ONE Unicode scalar value, written as a raw
character (`'A'`, `'€'`) or an escape (`'\n'`, `'\u{20AC}'`). This error means the content
between the quotes is not a single valid scalar.

The causes:

| content        | why it fails                                             |
|----------------|----------------------------------------------------------|
| `''`           | empty — a char must hold one codepoint                   |
| `'ab'`         | more than one codepoint                                  |
| `'\q'`         | unknown escape                                           |
| `'\xZZ'`       | `\xNN` needs two hex digits                              |
| `'\u{}'`       | `\u{…}` needs at least one hex digit and braces          |
| `'\u{D800}'`   | a UTF-16 surrogate is not a Unicode scalar value         |
| `'\u{110000}'` | past the last codepoint (`0x10FFFF`)                     |

```
fn main() -> int {
    c := 'ab'                // error: char literal must hold exactly one codepoint
    return 0
}
```

The escapes a char literal accepts: `\n` `\t` `\r` `\0` `\\` `\'` `\xNN` (a byte,
two hex digits) and `\u{HEX…}` (a Unicode scalar, up to `0x10FFFF`, no surrogates).

Fixes:

- Use exactly one character or one escape: `'a'`, `'\n'`, `'\u{20AC}'`.
- For text longer than one codepoint, use a string literal (`"ab"`) instead.
- Give `\u{…}` a value in `0..=0x10FFFF` that is not a surrogate (`0xD800..=0xDFFF`).
