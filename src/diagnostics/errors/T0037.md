# T0037: extern invalid type

An `extern fn` may only use the scalar C-ABI types the backend can marshal across
the AAPCS64 boundary: `int` (any width), `rawptr`, and `bool`. A parameter or return
type outside that set — a `str`, a struct, an enum, or `()` in return position with a
non-scalar spelling — is rejected.

```
extern fn puts(s: str) -> int   // error: str is not a valid extern type
```

Fixes:

- Pass a `rawptr` (a C `void*`/`char*`) instead of a `str`.
- Restrict parameters and the return type to `int`, `rawptr`, or `bool`.
