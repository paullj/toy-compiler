# T0037: extern invalid type

An `extern fn` may only use the C-ABI types the backend can marshal across the
AAPCS64 boundary: `int` (any width), `rawptr`, `bool`, and `str` (a `{ptr,len}`
reg-pair that spreads to a C `(const char* buf, size_t len)` argument pair). A
parameter or return type outside that set — a struct, an enum, or `()` in return
position with a non-scalar spelling — is rejected.

```
extern fn frobnicate(p: Point) -> int   // error: a struct is not a valid extern type
```

Fixes:

- Pass a `str` (spread to a C `buf, len` pair), a `rawptr` (a C `void*`), or a scalar.
- Restrict parameters and the return type to `int`, `str`, `rawptr`, or `bool`.
