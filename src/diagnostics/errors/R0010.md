# R0010: extern not in core

An `extern fn` declaration is only allowed inside a bundled `core/` module — the
quarantined unsafe boundary where the toy standard library binds C-ABI symbols. A
user program reaches C functions through a safe `std/` wrapper, never by declaring
its own `extern`.

```
extern fn labs(x: int) -> int   // error in a user file: extern is core-only
```

Fixes:

- Call the safe wrapper the standard library provides (e.g. `std/math.abs`).
- If you are extending the standard library, put the `extern fn` in a `core/`
  module and expose a safe wrapper from `std/`.
