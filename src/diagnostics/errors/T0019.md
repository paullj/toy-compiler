# T0019: mutating method requires a mutable place

A method declared with a `mut self` receiver mutates the receiver in place: the
call passes the receiver *by address*, so the receiver must be a mutable,
addressable variable — a local, or a field of one — not a temporary value.

```
struct P { x: int, y: int }
impl P { fn bump(mut self, d: int) { self.x = self.x + d } }

fn main() -> int {
    P{ x: 40, y: 0 }.bump(2)   // error: receiver is a temporary, not a place
    return 0
}
```

Bind the receiver to a local first, then call the method on it:

```
fn main() -> int {
    p := P{ x: 40, y: 0 }
    p.bump(2)                  // ok: `p` is a mutable local
    return p.x
}
```

A field of a local is also a valid receiver (`q.inner.bump(2)` when `q` is a
local). A plain `self` (by-value) method has no such restriction — it copies the
receiver and can be called on any value, including a temporary.
