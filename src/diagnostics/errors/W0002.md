# W0002: unused parameter

A function parameter was declared but never referenced in the body. The parameter
does nothing, which usually means a typo, a leftover from an edit, or a value the
body was meant to use.

Prefix the name with an underscore to mark it deliberately unused: rename `x` to
`_x`. A parameter named `self` (the conventional method receiver) is exempt and
never warns. This is a warning, so it does not fail the build; `--deny-warnings`
promotes it (and every warning) to an error, and `--allow W0002` silences it.
