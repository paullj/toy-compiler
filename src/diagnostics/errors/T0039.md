# T0039: arity mismatch

A function or method call passes the wrong number of arguments. The diagnostic
renders the callee's parameter-type signature and points a secondary label at the
definition, so the shape it expects is visible at the call site.

```
fn add(a: int, b: int) -> int { return a + b }

add(1)   // error: expected 2 argument(s), got 1; 'add' takes (int, int)
```

Fixes:

- Pass exactly as many arguments as the signature lists.
- Follow the "previously defined here" label to the definition to see the parameters.
