# T0017: instantiation too deep

A generic data type instantiated itself at an ever-larger type argument, so the
monomorphizer would never reach a fixpoint. Each level nests the previous type
inside a generic application (`Box[int]`, `Box[Box[int]]`, `Box[Box[Box[int]]]`,
…), so the set of concrete instances is infinite.

```
struct Box[T] { v: T }
fn go[T](x: T) { go[Box[T]](Box[Box[T]]{ v: x }) }   // T grows every call
fn main() { go[int](0) }
```

The compiler bounds the generic-nesting depth of a type argument and rejects the
program here — deterministically, never hanging or running out of memory. Break
the recursion so the type arguments stop growing (a legitimately deep-but-finite
generic program still compiles).
