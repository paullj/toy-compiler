# T0022: mutating method not supported on a builtin scalar

A method declared with a `mut self` receiver mutates the receiver in place: the
call passes the receiver *by address* so the body can write back through the
pointer. That ABI only works for `struct` and `enum` receivers, whose bodies
touch `self` exclusively through field access. A builtin scalar (`int`, `bool`,
`str`, `()`) uses `self` directly as a value, so passing its slot address would
make the body read and compute on the pointer itself.

```
impl int { fn bump(mut self) -> int { return self + 1 } }

fn main() -> int {
    x := 41
    return x.bump()   // error: mut self not supported on `int`
}
```

Use a plain (by-value) `self` method and return the new value, then rebind:

```
impl int { fn bump(self) -> int { return self + 1 } }

fn main() -> int {
    x := 41
    x = x.bump()      // ok: by-value receiver, result assigned back
    return x
}
```

A `mut self` method is fine on a `struct` or `enum` receiver that is a mutable
place (a local, or a field of one).
