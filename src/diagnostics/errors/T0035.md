# T0035: type alias forms a cycle

A `type Name = Target` alias is transparent: it resolves to the type its target names.
When a chain of aliases refers back to itself — directly or through other aliases —
there is no underlying type to resolve to, so the chain is rejected.

```
type A = B
type B = A       // error: type alias 'A' forms a cycle
fn main() -> int { return 0 }
```

A single self-reference is the same error:

```
type A = A       // error: type alias 'A' forms a cycle
fn main() -> int { return 0 }
```

Fixes:

- Point one alias in the chain at a concrete type (a builtin, a struct, or an enum),
  e.g. `type B = int`.
- Remove the alias that closes the loop.

An alias whose target is a real type (`type Celsius = int`, `type P = Point`) is fine —
only a target that transitively resolves back to the alias itself is a cycle.
