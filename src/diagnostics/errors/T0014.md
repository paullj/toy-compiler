# T0014: monomorphization instance limit exceeded

A generic function reached the compiler's ceiling on the number of concrete
instances it will monomorphize. Each `f[A](..)` call site with a distinct
concrete type-arg tuple reifies one more per-fn codegen unit; a program that
demands more than the (generous) limit trips this diagnostic instead of running
the checker out of memory.

In the current language this is effectively unreachable — type-args must already
be concrete, so the instance set is a finite closure of the source's explicit
call sites. It exists as a backstop for the recursive-instantiation hazard
generics introduce (a generic that instantiates itself at an ever-larger
type). Break that recursion to compile.
